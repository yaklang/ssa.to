命令行实践

从编译与查询，到扫描报告和 Program 管理。

📄️CLI 总览

理解编译、查询与扫描命令的分工，选择适合任务的命令行流程。

📄️编译与查询

把示例项目保存为 Program，再执行 SyntaxFlow 规则并复核命中位置。

📄️代码扫描与报告

配置扫描目标、规则与输出格式，阅读进度、风险与报告文件。

📄️Program 与结果管理

管理已编译 Program，清理历史数据，检查保存的分析结果。

📄️AI Agent 工作流程

将编译、规则编写与结果复核串联到现有 Agent 的工作流程中。
